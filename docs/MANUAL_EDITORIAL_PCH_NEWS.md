# PCH NEWS — Manual Editorial e Manual de Linguagem
## Versão 1.0 — 2026

### Identidade
**A voz que interrompe o silêncio.**

**Missão:** Informar com precisão. Contextualizar com inteligência. Comunicar com humanidade.

**Promessa:** Aqui você não recebe apenas a notícia. Você entende o que ela significa, por que importa e o que pode aprender com ela.

**Fórmula:** FATO + OBJETIVO + PÚBLICO + CONTEXTO → LINGUAGEM PCH.

### Os 7 movimentos PCH
1. CHAMAR
2. LOCALIZAR
3. EXPLICAR
4. CONECTAR
5. CONTRASTAR
6. SIGNIFICAR
7. DEIXAR UMA CHAVE

### Arquitetura padrão
Título → Linha fina → Abertura → Contexto → Desenvolvimento → Análise → Contraponto → Fechamento → Fontes.

### Tipos de conteúdo
Notícia, Reportagem, Análise, Coluna, Pílula do Poeta, Entrevista e Patrocinado.

### Apuração
Priorizar fontes primárias; cruzar informações; não apresentar rumor como fato; separar alegação, fato verificado e interpretação; buscar manifestação da parte citada quando necessário; nunca inventar números, citações, nomes, datas ou contexto; registrar limitações e corrigir com transparência.

### IA
A IA pode apoiar pesquisa, organização, transcrição, revisão, estrutura e primeiro rascunho. Não é fonte. A responsabilidade editorial final é humana.

### Checklist de publicação
Fato confirmado? Fontes identificadas? Nomes/datas/números conferidos? Contraditório quando necessário? Fato/opinião separados? Título corresponde? Abertura entrega relevância? Leitor leigo entenderia? PCH acrescenta compreensão? Há chave final? Conteúdo comercial identificado? Imagens com direito/crédito? Revisão final?

### Algoritmo editorial
FATO → FONTE → CONTEXTO → IMPACTO → CONTRAPONTO → SIGNIFICADO → CHAVE FINAL → DISTRIBUIÇÃO.

### Regra-mãe
Fazer o leitor sentir que alguém parou para ajudá-lo a entender, e não apenas para contar o que aconteceu.

**Não escrevemos para ocupar espaço. Escrevemos para deixar compreensão.**
